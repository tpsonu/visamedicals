# VisaMedicals Pro - Next-Generation Medical & Shipping Visa Platform

VisaMedicals Pro is a modern, high-performance web application designed for Medical Clinics, GCC / GAMCA Visa Centers, and DG Shipping Maritime Seafarer Examination Centers.

## Key Features
1. **GCC & Maritime Patient Intake**: Auto country fee calculation, WebRTC webcam photo capture, simulated biometric fingerprint scanner, and token queue assignment.
2. **Live Token Queue Board**: Real-time candidate tracking across Reception, Lab Diagnostics, Physical Exam, Doctor Signoff, and Certificate Ready stages.
3. **Laboratory Diagnostic Suite**: Blood serology (HIV, HBsAg, Anti-HCV, VDRL, TPHA), biochemistry, hematology, urine, stool, and automated machine analyzer sync simulation.
4. **Clinical Examination & Doctor Signoff**: Visual acuity, hearing audiometry, vitals, systemic physical exam, doctor remarks, and FIT / UNFIT determination.
5. **Vaccine Inventory & Expiry Tracker**: Item catalog, stock count, batch expiry warning alerts, supplier management, and auto stock deduction on patient intake.
6. **MOFA Data Tracker**: Reference upload and verification portal.
7. **Consolidated Reports & Export**: Diagnostic register, vaccination report, financial revenue statement, and CSV / Excel exporter.
8. **Print Engine**: Official GCC Embassy & Seafarer Fit Certificates with QR code verification, clinic logo, doctor stamp, and watermark.

## How to Run

### 1. Start Node API Server (Port 5000)
```bash
npm run server
```

### 2. Start Frontend App (Port 5173)
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.
